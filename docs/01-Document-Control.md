## 1.3 Document Purpose

This document defines the complete set of functional, non-functional, data, validation, business-rule, and behavioural requirements for the Inventory Management System.

It serves as the authoritative baseline for subsequent design, implementation, and testing activities.

## 1.4 Intended Audience

- Students implementing the system in C# / WinForms
- Course instructors / assessors
- Future maintainers of the documentation

## 1.5 Related Documents

This is the master requirements document. Subsequent documents (database design, class design, UI specification, test cases) will reference the requirement IDs defined herein.

## 1.6 Conventions

- **FR-xxx** — Functional Requirement
- **NFR-xxx** — Non-Functional Requirement
- **BR-xxx** — Business Rule
- **DR-xxx** — Data Requirement
- **VAL-xxx** — Validation Requirement
- **ER-xxx** — Error Handling Requirement
- **UC-xxx** — Use Case
- **WF-xxx** — Workflow
- **OBJ-xxx** — Objective
- **Must / Shall** — Mandatory
- **Should** — Recommended
- **May** — Optional

All requirements are written to be observable and testable.
