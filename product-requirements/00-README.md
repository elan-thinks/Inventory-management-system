# NovaTech Electronics — Inventory Management System

## Product Requirements + UX/UI Specification

This package translates approved SRS v1.0 into product, UX, and UI requirements. The SRS remains the source of truth.

### Approval status

🟢 Approved with permission correction UX-DEC-001.

Inventory/Store Staff are view/search-only for Products, Categories, Suppliers, and Customers. Administrator-only controls manage master data. Staff may perform Stock-In and Stock-Out, but not Inventory Adjustment or User Management.

See `project-management/PRODUCT-UX-AUDIT.md` for the decision record.
